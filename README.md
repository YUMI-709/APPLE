# 一二三，木头人 · 小苹果篇

> 艾尔海森 × 卡维 · 同人向像素小游戏
> 青苹果闭上眼睛的时候，红苹果可以偷偷往前挪；他一回头，你就得立刻定住。

纯前端单页小游戏，浏览器打开即玩，零依赖、不联网、不需要安装任何东西。

---

## 玩法

每一轮里有一个人背着身闭眼，另一个人负责悄悄往前挪，碰到对方就算赢下这一轮，然后攻守交换，换你来当那个"闭着眼睛的人"。

他睁眼的那一瞬间你要是还在动，就会被抓个正着：退回起点、掉一颗心。三颗心掉光，这一局就结束了。轮数越高，他睁眼的时间越长、闭眼的时间越短，后面还会开始"偷看"——假装回头骗你冲出去。

每成功碰到对方 3 次可以抽一次奖，奖品共 8 种，抽到的会收进图鉴随时翻看。图鉴与抽奖进度保存在浏览器本地，关掉也不会丢。

## 操作

| | 电脑 | 手机 |
|---|---|---|
| 移动 | `←` `→` 或 `A` `D` | 按住屏幕左半 / 右半 |
| 暂停 | `ESC` / `P` | 右上角按钮 |
| 重来 | `R` | 右上角按钮 |
| 图鉴 | `T` | 右上角按钮 |
| 静音 | `M` | — |

手机建议横屏游玩。

## 目录结构

```
index.html          游戏本体（单文件，含全部逻辑、绘制与音乐合成）
assets/             像素素材（角色眨眼帧、背景、奖品图）
.nojekyll           告诉 GitHub Pages 不要走 Jekyll 处理
```

## 部署到 GitHub Pages

1. 新建仓库，把本目录下的文件（`index.html`、`assets/`、`.nojekyll`）上传到**仓库根目录**
2. 仓库 `Settings → Pages`，Source 选 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`
3. 稍等片刻，访问 `https://<你的用户名>.github.io/<仓库名>/`

所有资源都使用相对路径，放在仓库子路径下也能正常运行。
